================================================================================
HƯỚNG DẪN ĐẤU NỐI CHI TIẾT MẢNG DÒ LINE TCRT5000 5 MẮT VÀ DRIVER TB6612FNG
VỚI BẢNG MỞ RỘNG ESP32 SHIELD 30-PIN (CHUẨN HÀNG CHÂN S - V - G)
Dự án: Xe Dò Line Tự Hành & Cánh Tay Robot 4 Bậc - FEMA Mechatronics
================================================================================

I. ĐẶC ĐIỂM BẢNG MỞ RỘNG ESP32 SHIELD 30-PIN (EXPANSION BOARD):
--------------------------------------------------------------------------------
Bảng mở rộng cung cấp hệ thống chân cắm dồi dào, thuận tiện và an toàn:

1. CỔNG NHẬN NGUỒN PIN CHÍNH:
   - Giắc tròn DC màu đen ở góc dưới: In chữ [ DC6.5-16V ].
   - Dùng để cắm trực tiếp đầu ra từ khay 2 pin 18650 (7.4V - 8.4V).

2. KHUNG HỘP TRẮNG 8 CHÂN NGUỒN (ngay phía trên cổng Type-C):
   +---------------------------------------------------------------+
   |   [ 5V ]        [ 5V ]          [ 3V ]          [ 3V ]        | <- Hàng trên
   |   [ GND ]       [ GND ]         [ GND ]         [ GND ]       | <- Hàng dưới
   +---------------------------------------------------------------+

3. QUY ƯỚC 3 HÀNG CỌC KIM THEO CHUẨN S - V - G (Cả 2 mép bo mạch):
   +-------------------------------------------------------------------------+
   | CỘT NGOÀI CÙNG (Sát mép bo mạch) | Chữ [ S ] (Signal)  - Tín hiệu GPIO  |
   | CỘT Ở GIỮA                       | Chữ [ V ] (Voltage) - Nguồn điện     |
   | CỘT TRONG CÙNG (Sát chip ESP32)  | Chữ [ G ] (Ground)  - Cực âm / Mass  |
   +-------------------------------------------------------------------------+

4. JUMPER NGUỒN MÀU VÀNG:
   - Gạt nấc [ 5V ]: Toàn bộ hàng chân giữa [ V ] sẽ xuất mức 5V.
   - Gạt nấc [ 3.3V ]: Toàn bộ hàng chân giữa [ V ] sẽ xuất mức 3.3V.

================================================================================
II. HƯỚNG DẪN ĐẤU NỐI DRIVER ĐỘNG CƠ TB6612FNG (MẠCH ĐỎ):
================================================================================

1. NGUỒN VÀ TÍN HIỆU ĐIỀU KHIỂN TỪ SHIELD ESP32 SANG TB6612FNG:
+-------------------+---------------------------------------------------------+
| Chân trên TB6612  | Cắm vào vị trí này trên Shield mở rộng ESP32           |
+-------------------+---------------------------------------------------------+
| [ VM ]   (1 phải) | Cọc kim [ 5V ] thứ 1 (Trong khung hộp trắng 8 chân)     |
| [ GND ]  (3 phải) | Cọc kim [ GND ] thứ 1 (Trong khung hộp trắng 8 chân)    |
| [ STBY ] (4 trái) | Cọc kim [ 5V ] thứ 2 (Trong khung hộp trắng 8 chân)     |
| [ NC/VCC](2 phải) | Cọc kim [ 3V ] hoặc [ 5V ] (Cấp nguồn nuôi IC logic)    |
+-------------------+---------------------------------------------------------+
| [ AIN1 ] (3 trái) | Hàng [ S ] (Cột ngoài cùng) tại cọc [ D13 ] (GPIO 13)   |
| [ AIN2 ] (2 trái) | Hàng [ S ] (Cột ngoài cùng) tại cọc [ D12 ] (GPIO 12)   |
| [ BIN1 ] (5 trái) | Hàng [ S ] (Cột ngoài cùng) tại cọc [ D27 ] (GPIO 27)   |
| [ BIN2 ] (6 trái) | Hàng [ S ] (Cột ngoài cùng) tại cọc [ D26 ] (GPIO 26)   |
+-------------------+---------------------------------------------------------+

2. ĐẤU NỐI RA 2 ĐỘNG CƠ DC TT (BÁNH XE TRÁI & PHẢI):
+-------------------+---------------------------------------------------------+
| Chân trên TB6612  | Nối ra động cơ                                          |
+-------------------+---------------------------------------------------------+
| [ AO1 ]  (4 phải) | Dây 1 của Động cơ Bánh TRÁI                             |
| [ AO2 ]  (5 phải) | Dây 2 của Động cơ Bánh TRÁI                             |
| [ BO1 ]  (7 phải) | Dây 1 của Động cơ Bánh PHẢI                            |
| [ BO2 ]  (6 phải) | Dây 2 của Động cơ Bánh PHẢI                            |
+-------------------+---------------------------------------------------------+
(*) Lưu ý: Nếu khi chạy thử bánh xe quay ngược chiều, chỉ cần đảo chéo 2 dây AO1/AO2
    hoặc BO1/BO2 cho nhau.

================================================================================
III. HƯỚNG DẪN ĐẤU NỐI MẢNG CẢM BIẾN DÒ LINE TCRT5000 5 MẮT:
================================================================================

Mảng 5 mắt được bố trí thành một thanh ngang đặt chúc đầu xuống mặt sân:
  [ Mắt 1 - S1 ]  [ Mắt 2 - S2 ]  [ Mắt 3 - S3 ]  [ Mắt 4 - S4 ]  [ Mắt 5 - S5 ]
    (Ngoài Trái)    (Giữa Trái)      (Trung tâm)     (Giữa Phải)     (Ngoài Phải)

1. CẤP NGUỒN CHO MẢNG CẢM BIẾN:
+-------------------+---------------------------------------------------------+
| Chân TCRT5000 5CH | Cắm vào vị trí trên Shield ESP32                        |
+-------------------+---------------------------------------------------------+
| [ VCC ]           | Cọc [ 3V ] (Khung hộp trắng) hoặc hàng [ V ] nấc 3.3V   |
| [ GND ]           | Cọc [ GND ] (Khung hộp trắng) hoặc hàng [ G ]           |
+-------------------+---------------------------------------------------------+
(*) Khuyến nghị: Cấp 3.3V (chân 3V) để tín hiệu xuất ra từ cảm biến có điện áp
    3.3V chuẩn, bảo vệ an toàn tuyệt đối 100% cho các cổng vào GPIO của ESP32.

2. CÁC CHÂN TÍN HIỆU SỐ DIGITAL OUTPUT (OUT1 -> OUT5):
Cắm trực tiếp vào CỘT NGOÀI CÙNG [ S ] của các chân GPIO tương ứng:
+-------------------+----------+----------------------------------------------+
| Chân trên cảm biến| Vị trí S | Chức năng trong thuật toán bám line PID      |
+-------------------+----------+----------------------------------------------+
| [ OUT1 ] / [ D1 ] | [ D34 ]  | Mắt 1 (Trái ngoài cùng) - Xử lý cua vuông 90°|
| [ OUT2 ] / [ D2 ] | [ D35 ]  | Mắt 2 (Trái trong)      - Bẻ lái trái vừa    |
| [ OUT3 ] / [ D3 ] | [ D32 ]  | Mắt 3 (Chính giữa)      - Bám tâm line/Thẳng |
| [ OUT4 ] / [ D4 ] | [ D19 ]  | Mắt 4 (Phải trong)      - Bẻ lái phải vừa    |
| [ OUT5 ] / [ D5 ] | [ D21 ]  | Mắt 5 (Phải ngoài cùng) - Xử lý cua vuông 90°|
+-------------------+----------+----------------------------------------------+

(*) PHƯƠNG ÁN DỰ PHÒNG CHÂN NỐI (Nếu Shield của bạn không có cọc D34/D35):
    - Mắt 1 (OUT1): Hàng [ S ] tại [ D32 ]
    - Mắt 2 (OUT2): Hàng [ S ] tại [ D33 ]
    - Mắt 3 (OUT3): Hàng [ S ] tại [ D25 ]
    - Mắt 4 (OUT4): Hàng [ S ] tại [ D19 ]
    - Mắt 5 (OUT5): Hàng [ S ] tại [ D21 ]
    (Cả hai phương án trên đều tuyệt đối không trùng chân với Động cơ hay Cánh tay).

================================================================================

| GPIO     | Cột trên Bo   | Chức năng phần cứng                              |
+----------+---------------+--------------------------------------------------+
| GPIO 13  | D13 (Cột S)   | TB6612 AIN1 (Động cơ Bánh Trái)                  |

| GPIO 27  | D27 (Cột S)   | TB6612 BIN1 (Động cơ Bánh Phải)                  |

| GPIO 34  | D34 (Cột S)   | TCRT5000 Mắt 1 - Far Left (Ngoài cùng bên Trái)  |
| GPIO 35  | D35 (Cột S)   | TCRT5000 Mắt 2 - Mid Left (Bên Trái)             |
| GPIO 32  | D32 (Cột S)   | TCRT5000 Mắt 3 - Center (Chính giữa vạch)        |
| GPIO 19  | D19 (Cột S)   | TCRT5000 Mắt 4 - Mid Right (Bên Phải)            |
| GPIO 21  | D21 (Cột S)   | TCRT5000 Mắt 5 - Far Right (Ngoài cùng bên Phải) |

| GPIO 5   | D5  (Cột S)   | Cảm biến siêu âm RCWL-1601 Trig (Phát xung)      |

+----------+---------------+--------------------------------------------------+
| GPIO 14  | D14 (Cột S)   | Dự phòng: Servo Base (Đế cánh tay robot)         |
| GPIO 22  | D22 (Cột S)   | Dự phòng: Servo Shoulder (Vai cánh tay robot)    |
| GPIO 23  | D23 (Cột S)   | Dự phòng: Servo Elbow (Khuỷu cánh tay robot)     |
| GPIO 15  | D15 (Cột S)   | Dự phòng: Servo Gripper (Kẹp cánh tay robot)     |
+----------+---------------+--------------------------------------------------+
| GPIO 2   | D2  (LED)     | Đèn LED báo trạng thái Wi-Fi & Failsafe          |

+----------+---------------+--------------------------------------------------+

V. QUY TRÌNH KIỂM TRA HIỆU CHUẨN SAU KHI CẮM DÂY:
================================================================================

1. KIỂM TRA NGUỒN ĐIỆN VÀ AN TOÀN:
   - Kê gầm xe lên giá đỡ để 2 bánh không chạm đất khi thử nghiệm.
   - Cắm jack nguồn pin 18650 vào cổng [ DC6.5-16V ] -> Bật công tắc pin.
   - Quan sát đèn LED đỏ trên Shield ESP32 và module TCRT5000 đều sáng.
   - Dùng tay sờ chip TB6612FNG: Chip mát mẻ, không có hiện tượng nóng bất thường.

2. CÂN CHỈNH ĐỘ NHẠY CHO 5 MẮT TCRT5000:
   - Đặt thanh cảm biến lên trên nền trắng (cách mặt sàn khoảng 1cm - 1.5cm):
     -> Cả 5 đèn LED báo tín hiệu trên thanh cảm biến phải SÁNG.
   - Đưa vạch băng dính đen lần lượt lướt qua từng mắt (từ Mắt 1 đến Mắt 5):
     -> Mắt nào gặp vạch đen thì đèn LED tương ứng của mắt đó phải TẮT ngay lập tức.
   - Nếu có mắt chưa nhạy hoặc sáng liên tục:
     -> Dùng tuốc-nơ-vít xoay nhẹ biến trở tinh chỉnh trên thanh cảm biến để cài đặt
        ngưỡng phân biệt trắng/đen tối ưu nhất.

3. NGUYÊN LÝ TÍNH SAI SỐ VỊ TRÍ PID VỚI 5 MẮT:
   + [ 1 0 0 0 0 ] : Sai số = -4  -> Cua gắt sang TRÁI hết cỡ
   + [ 1 1 0 0 0 ] : Sai số = -3  -> Cua trái mạnh
   + [ 0 1 0 0 0 ] : Sai số = -2  -> Bẻ lái trái vừa
   + [ 0 1 1 0 0 ] : Sai số = -1  -> Nhích nhẹ sang trái
   + [ 0 0 1 0 0 ] : Sai số =  0  -> Vạch đen chính giữa -> ĐI THẲNG TỐC ĐỘ CAO
   + [ 0 0 1 1 0 ] : Sai số = +1  -> Nhích nhẹ sang phải
   + [ 0 0 0 1 0 ] : Sai số = +2  -> Bẻ lái phải vừa
   + [ 0 0 0 1 1 ] : Sai số = +3  -> Cua phải mạnh
   + [ 0 0 0 0 1 ] : Sai số = +4  -> Cua gắt sang PHẢI hết cỡ
   + [ 1 1 1 1 1 ] : Gặp vạch ngang ngã tư hoặc vạch đích dừng xe.
   + [ 0 0 0 0 0 ] : Mất line hoàn toàn -> Kích hoạt cơ chế tìm lại line theo sai số gần nhất.
